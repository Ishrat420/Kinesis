# KD-003 — Custom Object Fields

**Status:** Idea
**Priority:** High

## Summary

Allow users to add custom fields to objects.

The user provides:

```text
Field name
[ Strength ]

Field type
[ Text ▾ ]
```

Initial supported field types:

* Text
* Number
* Date
* Checkbox
* Select
* Currency
* URL
* Kinesis Link

Fields can be added and configured independently for each object.

## Notes

This forms a core capability of configurable modules and freestyle objects.
