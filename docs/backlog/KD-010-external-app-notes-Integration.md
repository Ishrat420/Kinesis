### KD-010 — External App & Notes Integration

**Status:** Idea
**Priority:** Medium
**Tags:** Integration, Needs Research

## Summary

Explore allowing Kinesis objects to link to content stored in external applications, particularly note-taking and knowledge-management tools.

Examples:

* Notion
* Obsidian
* Google Docs
* Other note-taking applications

This may include research, brainstorming, reference material, notes, reasoning, or a record of the decision-making process that led to a particular outcome.

For example, a user working toward a goal may have researched different approaches, brainstormed how to break the goal into milestones, or documented why they chose a particular strategy. That information should be attachable to the goal—and potentially individual milestones—so the context is preserved and can be easily referenced later.

## Requirements
The core requirement is that users should be able to create, attach and retain supporting notes that they had to make, wherever it is relevant in Kinesis.

Without seamless integration or native note capability it will be hard to create notes easily within Kinesis. 

The intention is not necessarily for Kinesis to become a full note-taking application. The requirement is that important context should not have to live disconnected from the thing it relates to.

## Consideration

Also evaluate whether Kinesis would benefit from a lightweight native note capability for attaching simple notes to objects without becoming a dedicated note-taking application.

Kinesis should complement specialised tools rather than unnecessarily recreate them. Kinesis could satisfy this through lightweight native notes, attachments, links to external note-taking tools, or a combination of these approaches.
