# KD-008 — Add a quick capture 

**Status:** Idea
**Priority:** Low

## Summary

Introduce **Quick Capture** as a fast way to record something without requiring the user to immediately decide where it belongs in Kinesis.

The purpose is simple:

> Capture now. Organise later.

## Behaviour

Quick Capture should require minimal information:

```text
What do you want to remember?
[ ______________________________ ]

Due date (optional)
[ __________ ]

[ Save ]
```

Captured items are stored in an **Inbox** until organised or dismissed.

## Future Behaviour

Users may later be able to:

* Convert captured items into reminders, goals, documents, or module objects via one click action. 
* Link captures to existing objects.
* Add priority if relevant. 
* Use AI/rule-based suggestions to recommend where an item belongs.
* Capture using a keyboard shortcut or mobile quick action.

## Notes

Quick Capture should remain intentionally lightweight. It should not become another full object-creation form.

Not required for MVP; retain the concept for future development.
