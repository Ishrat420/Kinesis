### KD-012 — Starter / Example Data

**Status:** Idea
**Priority:** Medium
**Tags:** UX / UI, Foundation Dependent

## Summary

Ship Kinesis with basic example data so a new installation does not initially feel empty and users can immediately understand how features are intended to work.

Examples could include:

```text
Documents
Example Passport

Goals
Example: Build an emergency fund
├── Save first $1,000
├── Reach $5,000
└── Reach $10,000

Finance
Example Savings Account

Relationships
Example Person
```

Example data should demonstrate fields, reminders, links, milestones and other important behaviours.

## Behaviour

Example content should be clearly identified as sample data and easy to:

* Edit
* Delete
* Replace with real information
* Remove entirely

Consider integrating this with **KD-012 — Guided Onboarding**, allowing users to choose whether to start with examples or an empty Kinesis.
