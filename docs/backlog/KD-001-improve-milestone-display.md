# KD-001-improve-milestone-display

**Status:** Planning Needed

**Priority:** Medium 

## Summary 

When adding a measurable target in the milestone, it should say:

[Milestone] [Target value] [UNIT] 

All in one line. 

It is currently not doing that. 

It should also do a better job at indicating the behaviour of this role of Numeric value and how it is used.
