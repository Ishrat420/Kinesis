# KD-030 — Create To-Do from To-Do Screen

**Status:** Accepted 
**Priority:** High  
**Tags:** UX/UI

## Summary

Allow users to create a new To-Do directly from the To-Do screen.

## Requirements

Add a clear **+ New To-Do** action.

Creation should support all currently available To-Do details, including:

- Title — required
- Kinesis Link
- Status
- Due

A To-Do must also be creatable with only a title.

## Behaviour

- Save using the existing To-Do/Object architecture.
- Reuse existing logic and capabilities.
- New To-Dos should appear immediately in the To-Do view and other relevant surfaces.
- Use the existing logic , do not create new one.
